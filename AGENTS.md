# AGENTS.md

## Collaboration Rules

- Aniket is the backend developer.
- Unless I specifically say I am Aniket, assume I am a frontend developer.
- You are not allowed to touch backend code or any configuration files.
- If backend changes are needed, do not implement them directly.
- Instead, write a backend modification proposal that can be sent to Aniket.

## Backend Modification Proposal Template

When backend work is required, provide a proposal in this format:

1. Objective
2. Why this backend change is needed
3. Exact files that should be changed
4. Proposed code-level changes
5. API/DB/schema impact
6. Risks and rollback plan
7. Validation steps
